# 游戏设计文档

## 游戏名称
**我要消十个**

## 游戏简介
一款基于 HTML5 Canvas 的休闲消除游戏。玩家通过滑动连接 4 个或更多同色方块进行消除，消除越多单次得分越高。游戏包含旋转棋盘、彩色方块（万能桥接）等独特机制，共 50 个关卡，难度递进。

## 核心玩法

### 基本规则
- 2D 棋盘上分布着不同颜色的方块
- 玩家用手指（或鼠标）连续划过 4 个或更多同色方块即可消除
- 消除后上方方块因重力下落填补空缺
- 限时内达到目标分数即为通关

### 计分规则
- 消除 n 个方块得 (n-3)×10 分
- 消除 4 个 = 10 分，5 个 = 20 分，6 个 = 30 分，以此类推
- 鼓励一次性划更多的方块

### 棋盘旋转
- 棋盘左右两侧及上方各有一个操控条
- 左条：棋盘逆时针旋转 90°
- 右条：棋盘顺时针旋转 90°
- 上条：棋盘翻转 180°
- 旋转后重力重新作用，方块下落

### 彩色方块（万能桥接）
- 彩色方块可以连接任意颜色的方块
- 划过彩色方块后，下一个方块可以是任意颜色
- 彩色方块不能作为滑动起点
- 出现在第 9 关及以后

### 打乱机制
- 每关 2 次主动打乱机会
- 点击右上角 ↺ 按钮，剩余方块颜色重新随机排列

## 技术实现

### 技术栈
- HTML5 Canvas 渲染
- 原生 JavaScript（无框架）
- Web Audio API 音效
- 无第三方依赖

### 核心模块
| 模块 | 功能 |
|------|------|
| board.js | 棋盘逻辑：网格、消除、重力、旋转、彩色方块 |
| game.js | 游戏主循环、状态管理、动画系统 |
| renderer.js | Canvas 渲染：方块、路径、HUD、特效 |
| input.js | 触摸/鼠标输入处理、滑动路径检测 |
| particles.js | 粒子系统：破碎特效、加分弹窗 |
| audio.js | Web Audio API 音效系统 |

### 游戏机制
- **重力系统**：方块按列分段下落，砖块作为障碍物分隔段落
- **旋转系统**：网格矩阵 90°/180° 变换，旋转后重力重新作用
- **彩色方块**：万能桥接，可连接任意颜色，路径中可切换颜色
- **动画系统**：方块下落加速曲线、旋转画布变换、粒子特效
