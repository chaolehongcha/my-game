# 游戏设计文档

## 一、设计原点

### 1.1 灵感来源
基于制作休闲游戏的需求，我广泛游玩了来自 Google Play 和抖音小游戏平台排名靠前的休闲游戏，初步确定了制作方向。在游玩过程中，有三类休闲游戏玩法吸引了我的目光：

**1. 配对消除类** — 通过匹配相同元素进行消除，操作直观，反馈即时。

**2. 物体下落类** — 方块受重力影响下落堆叠，物理感带来独特的操作乐趣。

**3. 数学逻辑类** — 结合数字运算与策略规划，玩法深度高。

商业上的成功已经证明了这些游戏玩法有独特的魅力。如果把这三类游戏结合起来，能否创造出更好玩的体验？

### 1.2 设计理念
我认为优秀休闲游戏的关键是：**核心机制简单**。因此，即使借鉴上述三类游戏，也不能不加挑剔地全部拿来融合，而是克制地选择尽可能少且结合起来尽可能有趣的机制。

"我要消十个"诞生于一个朴素的念头：消除游戏的爽感源自"一次搞定一大片"。传统三消每次只消三个，节奏偏慢。如果把门槛提高到四个，但让玩家可以自由滑动、一次性划走任意多的同色方块，会怎样？

答案是：**消除越多越爽，策略也随之加深**。玩家不再机械地找三个，而是观察全局、规划路径、追求一次消除十个甚至更多——这就是名字的由来。

### 1.3 融合创新
从三类游戏中提取的核心机制：

| 来源 | 提取的机制 | 在本游戏中的体现 |
|------|-----------|----------------|
| 配对消除类 | 同色匹配消除 | 滑动连接 4+ 同色方块消除 |
| 物体下落类 | 重力下落 | 消除后上方方块重力下落填补 |
| 数学逻辑类 | 策略规划 | 计分公式 (n-3)×10，追求大范围消除 |

## 二、游戏概述

### 2.1 基本信息
- **游戏名称**：我要消十个
- **游戏类型**：H5 休闲消除游戏
- **技术栈**：HTML5 Canvas + 原生 JavaScript + Web Audio API
- **运行环境**：移动端/桌面端浏览器，零外部依赖

### 2.2 游戏简介
一款基于 HTML5 Canvas 的休闲消除游戏，玩家通过滑动连接 4 个或更多同色方块进行消除，单次消除数量越多得分越高。游戏包含棋盘旋转、彩色方块（万能桥接）、砖块障碍物等机制，共 50 个关卡，难度逐级递进。

## 三、核心玩法

### 3.1 基本规则
1. 棋盘上分布着不同颜色的方块，玩家用手指（或鼠标）连续划过 4 个或更多同色方块即可消除
2. 消除后，上方方块因重力下落填补空缺，形成新的消除机会
3. 限时内达到目标分数即可通关，超时则游戏失败

### 3.2 计分规则
- 消除 n 个方块得 (n-3)×10 分
- 消除 4 个 = 10 分，5 个 = 20 分，6 个 = 30 分，以此类推
- 鼓励一次性划取更多方块，而非多次小范围消除

### 3.3 棋盘旋转
棋盘左、右、上三侧设有操控条，点击可旋转棋盘：
- 左侧操控条：棋盘逆时针旋转 90°
- 右侧操控条：棋盘顺时针旋转 90°
- 上方操控条：棋盘翻转 180°
- 旋转后重力重新作用，方块下落，形成新的消除路径

### 3.4 彩色方块（万能桥接）
- 彩色方块（★ 图标）可连接任意颜色的方块，充当桥接媒介
- 划过彩色方块后，路径颜色自动切换为下一个方块的颜色
- 彩色方块不能作为滑动的起点
- 第 9 关起开始出现，后续关卡中逐步增加

### 3.5 打乱机制
- 每关拥有 2 次主动打乱机会
- 点击右上角 ↺ 按钮，剩余方块颜色重新随机排列
- 适用于死局或需要重新规划消除策略时使用

### 3.6 砖块障碍物
- 砖块（▣）不可移动、不可消除
- 不受重力影响，将棋盘分割为独立段落
- 重力仅在同段落的方块之间生效

## 四、关卡设计

### 4.1 教学关（1-5 关）
教学关在游戏开始时展示提示文字，引导玩家逐步学习核心机制：

| 关卡 | 教学主题 | 棋盘 | 颜色数 | 目标分 | 设计意图 |
|------|---------|------|--------|--------|---------|
| 1 | 划过同色方块（最少四个）！ | 5×5 十字形 | 2色 | 30 | 学习基本的滑动消除与重力下落 |
| 2 | 旋转平台！ | 5×5 | 2色 | 10 | 学习通过旋转聚拢同色方块 |
| 3 | 小心掉落！ | 5×5 空心 | 3色 | 70 | 学习大范围消除，消除越多得分越高 |
| 4 | 一次消除越多，加分更多！ | 5×5 | 1色 | 90 | 体验一次性消除 12 个方块的高分快感 |
| 5 | 彩石可以连接任何颜色！ | 5×5 | 2色 | 10 | 学习彩色方块的桥接用法 |

| 关卡范围 | 棋盘 | 颜色数 | 目标分范围 | 说明 |

| 6-10 | 5×5 | 3色 | 50-70 | 入门阶段，巩固基础操作 |
| 11-20 | 6×6 | 3色 | 80-120 | 初级阶段，棋盘扩大，增加策略性 |
| 21-35 | 7×7 | 3色 | 120-160 | 中级阶段，含彩色方块与砖块组合 |

## 五、技术实现

### 5.1 技术选型
- **渲染引擎**：HTML5 Canvas 2D
- **编程语言**：原生 JavaScript（ES6+）
- **音效系统**：Web Audio API
- **外部依赖**：零依赖

### 5.2 核心模块架构

| 模块 | 文件 | 职责 |
|------|------|------|
| 棋盘逻辑 | board.js | 网格管理、方块消除、重力下落、旋转变换、彩色方块桥接 |
| 游戏主控 | game.js | 游戏状态机、动画调度、关卡管理、计时系统 |
| 渲染引擎 | renderer.js | Canvas 绘制、方块渲染、路径高亮、HUD、特效 |
| 输入处理 | input.js | 触摸/鼠标事件、滑动路径追踪、按钮点击检测 |
| 粒子系统 | particles.js | 方块破碎特效、加分弹窗动画、光环闪烁 |
| 音效系统 | audio.js | 基于 Web Audio API 的合成音效 |
| UI 管理 | ui.js | 主菜单、关卡选择、结算界面 |
| 关卡数据 | generated-levels.js | 50 关固定布局数据 |

### 5.3 核心机制实现

**重力系统**
- 方块按列处理，砖块作为障碍物将列分割为独立段落
- 每段落内，方块从下往上依次下落填补空缺
- 下落动画采用加速曲线（ease-in），增强物理感

**旋转系统**
- 通过矩阵坐标变换实现 90° / 180° 旋转
- 旋转过程分为两阶段：先画布变换显示旋转动画，再应用重力
- 跨段落的方块在旋转后保持相对位置

**彩色方块**
- 网格中标记为 -2（特殊值）
- 桥接逻辑：允许路径在彩色方块处切换颜色
- 路径起点必须为普通方块，不能从彩色方块开始

**粒子系统**
- 方块消除时触发破碎粒子，颜色与方块一致
- 加分弹窗显示 "+分数"，带缩放入场动画
- 高分（+70 以上）显示金色特效与光环

### 5.4 音效系统
- 使用 Web Audio API 合成音效，无需外部音频文件
- 消除音效：根据消除数量分档（+10 轻音 / +30 中音 / +50 强音 / +70+ 辉煌音）
- 特殊音效：死局气泡音、通关胜利音
