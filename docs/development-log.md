# 开发过程日志

## 迭代记录

### 版本 0.1 - 2026-08-20

#### 本轮做了什么
- 确定玩法：滑动连接 4+ 同色消除 + 重力下落 + 左右移位 + 限时通关
- 实现核心 Board 类：网格初始化、方块消除、重力下落、左右移位、可解性检测
- 实现滑动路径追踪：连续同色路径检测，4方向相邻限制
- 实现 Canvas 渲染：方块绘制、路径高亮、箭头按钮、HUD 计时器
- 实现关卡系统：第1关手配（6×6, 3色, 60s），其余随机生成
- 搭建完整项目结构和文档

#### 自己玩完的感觉
- 第1关布局对称，容易上手
- 滑动反馈流畅，路径高亮清晰
- 左右移位有效帮助聚拢同色方块

#### 发现的问题
- 随机生成关卡可能出现无可消除局面 -> 加入 _ensureSolvable() 检测
- 触摸设备上滑动可能触发页面滚动 -> 已阻止默认行为
- 移位后可能打乱已有连接 -> 这是设计意图，增加策略性
