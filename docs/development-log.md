# 开发过程日志

## 迭代记录

### 版本 0.1 — 基础搭建
**日期：2026-08-20**

#### 本轮做了什么
- 确定核心玩法：滑动连接 4+ 同色方块消除 + 重力下落 + 左右移位 + 限时通关
- 实现 Board 核心类：网格初始化、方块消除、重力下落、可解性检测
- 实现滑动路径追踪：连续同色路径检测，4 方向相邻约束
- 实现 Canvas 渲染：方块绘制、路径高亮、箭头按钮、HUD 计时器
- 搭建完整项目结构，创建设计文档与开发日志框架

#### 自己玩完的感觉
- 第 1 关布局对称，容易上手
- 滑动反馈流畅，路径高亮清晰
- 左右移位有效帮助聚拢同色方块

#### 发现的问题
- 随机生成关卡可能出现无可消除的局面 → 加入可解性检测
- 触摸设备上滑动可能触发页面滚动 → 已阻止默认行为

### 版本 0.2 — 机制完善

#### 本轮做了什么
- 通关条件改为"达到目标分数"，而非清空棋盘
- 计分公式改为 (n-3)×10，鼓励大范围消除
- 加入死局气泡提示，不再强制结束游戏
- 加入重排按钮（每关 2 次）
- 加入重新开始按钮

#### 发现的问题
- 移位后方块穿过砖块 → 修复为按砖块分段滑动
- 重力让方块穿过砖块 → 修复为按砖块分段下落

### 最终游戏机制

| 机制 | 说明 |
|------|------|
| 滑动消除 | 4 个以上同色方块连续消除 |
| 重力下落 | 消除后上方方块下落填补 |
| 计分系统 | (n-3)×10，鼓励大范围消除 |
| 棋盘旋转 | 左/右/上三侧操控条，旋转 90° 或 180° |
| 彩色方块 | 万能桥接，可连接任意颜色 |
| 打乱 | 每关 2 次，重新排列方块颜色 |
| 砖块 | 障碍物，不受重力影响，分割棋盘段落 |
| 粒子特效 | 破碎特效、加分弹窗、光环动画 |
| 音效 | 不同分数段差异化音效 |
