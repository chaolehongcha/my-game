# 开发过程日志

## 迭代记录

### 版本 0.1 - 基础搭建
#### 日期
2026-08-20

#### 本轮做了什么
- 确定玩法：滑动连接 4+ 同色消除 + 重力下落 + 左右移位 + 限时通关
- 实现核心 Board 类：网格初始化、方块消除、重力下落、可解性检测
- 实现滑动路径追踪：连续同色路径检测，4方向相邻限制
- 实现 Canvas 渲染：方块绘制、路径高亮、箭头按钮、HUD 计时器
- 搭建完整项目结构和文档

#### 自己玩完的感觉
- 第1关布局对称，容易上手
- 滑动反馈流畅，路径高亮清晰
- 左右移位有效帮助聚拢同色方块

#### 发现的问题
- 随机生成关卡可能出现无可消除局面 -> 加入可解性检测
- 触摸设备上滑动可能触发页面滚动 -> 已阻止默认行为

### 版本 0.2 - 机制完善
#### 本轮做了什么
- 改为"达到目标分数"通关，而非清空棋盘
- 计分公式改为 (n-3)×10
- 加入死局气泡提示，不再强制结束
- 加入重排按钮（2次/关）
- 加入重新开始按钮

#### 发现的问题
- 移位后方块穿过砖块 -> 修复为按砖块分段滑动
- 重力让方块穿过砖块 -> 修复为按砖块分段下落
