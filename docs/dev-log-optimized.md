# 开发过程日志

## 版本 0.1 — 基础搭建

**日期：2026-08-20**

### 本轮做了什么
- 确定核心玩法：滑动连接 4+ 同色方块消除 + 重力下落 + 左右移位 + 限时通关
- 实现 Board 核心类：网格初始化、方块消除、重力下落、可解性检测
- 实现滑动路径追踪：连续同色路径检测，4 方向相邻约束
- 实现 Canvas 渲染：方块绘制、路径高亮、箭头按钮、HUD 计时器
- 搭建完整项目结构，创建设计文档与开发日志框架

### 自己玩完的感觉
- 第 1 关布局对称，容易上手
- 滑动反馈流畅，路径高亮清晰
- 左右移位有效帮助聚拢同色方块

### 发现的问题
- 随机生成关卡可能出现无可消除的局面 → 加入可解性检测
- 触摸设备上滑动可能触发页面滚动 → 已阻止默认行为

## 版本 0.2 — 机制完善

### 本轮做了什么
- 通关条件改为"达到目标分数"，而非清空棋盘，增加策略灵活度
- 计分公式改为 (n-3)×10，鼓励大范围消除
- 加入死局气泡提示，不再强制结束游戏
- 加入重排按钮（每关 2 次），提供容错机制
- 加入重新开始按钮

### 发现的问题
- 移位后方块穿过砖块 → 修复为按砖块分段滑动
- 重力让方块穿过砖块 → 修复为按砖块分段下落，砖块作为独立段落分隔符

---

## 版本 0.3 — 旋转系统

### 本轮做了什么
- 左右移位改为棋盘旋转（左 = 逆时针 90°，右 = 顺时针 90°）
- 加入上边框翻转 180°
- 设计三边框 UI 操控条
- 实现旋转动画（画布变换），两阶段：先旋转再重力

### 测试反馈
- 旋转比移位更直观，玩家更容易理解
- 旋转后重新布局带来新的消除策略

---

## 版本 0.4 — 彩色方块

### 本轮做了什么
- 加入彩色方块（万能桥接），可连接任意颜色
- 实现桥接逻辑：划过彩色方块后可切换颜色

## 版本 0.5 — 粒子特效与音效

### 本轮做了什么
- 粒子系统：方块破碎特效、加分弹窗、光环动画

- Web Audio API 音效：破碎音、加分音阶、死局音、通关音
- 加分弹窗缩放入场动画

## 版本 0.6 — 关卡设计

### 本轮做了什么
- 设计 5 个教学关（划消、旋转、大消、一次消除、彩石）
- 规划难度曲线：5×5 → 6×6 → 7×7 → 9×9 → 8×8
- 设计彩蛋关卡：笑脸、花朵、蝴蝶结、大树
- 砖块障碍物布局设计
- 关卡顺序重排

### 测试反馈与调整
- 第 2 关与第 3 关交换顺序：旋转教学应更早出现
- 第 40 关目标分从 220 下调至 180：难度过高
- 多处目标分微调，确保难度曲线平滑

### 最终游戏机制

| 机制 | 说明 | 引入关卡 |
|------|------|---------|
| 滑动消除 | 4 个以上同色方块连续消除 | 第 1 关 |
| 重力下落 | 消除后上方方块下落填补 | 第 1 关 |
| 计分系统 | (n-3)×10，鼓励大范围消除 | 第 1 关 |
| 棋盘旋转 | 左/右/上三侧操控条，旋转 90° 或 180° | 第 2 关 |
| 彩色方块 | 万能桥接，可连接任意颜色 | 第 5 关 |
| 打乱 | 每关 2 次，重新排列方块颜色 | 第 6 关 |
| 砖块 | 障碍物，不受重力影响，分割棋盘段落 | 第 1 关 |
| 粒子特效 | 破碎特效、加分弹窗、光环动画 | 第 1 关 |
| 音效 | 不同分数段差异化音效 | 第 1 关 |
